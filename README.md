# Customer Churn Prediction Pipeline & Web App

An end-to-end Machine Learning pipeline and interactive Streamlit web application to predict customer churn in real-time.

## Features
* **ML Pipeline:** Data preprocessing, standard scaling, one-hot encoding, and Random Forest classification.
* **Interactive Dashboard:** Built with Streamlit for real-time predictions.
* **Model Serialization:** Pipeline exported as `.pkl` file for smooth deployment.

## Tech Stack
* Python
* Scikit-Learn
* Pandas & NumPy
* Streamlit
* Joblib
